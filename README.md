# 埋点接收服务 · 离线缓存模拟器

零依赖（Node ≥ 18，无需 npm install）。演示浏览器埋点上报在弱网环境下的完整链路：

- **批量上报**：客户端按批量大小组包上报，批次级部分确认
- **离线缓存**：断网时事件缓存在 localStorage，重连后自动补发
- **幂等去重**：服务端按 `(deviceId, sessionId, seq)` 去重，重复事件丢弃但仍确认
- **乱序待处理**：序号超前的事件进入待处理区并保留原因，缺口补齐后自动晋升
- **部分成功只重试未确认部分**：响应按事件粒度返回 ack，客户端仅保留未确认序号重试
- **故障模拟**：服务端可开启「随机拒绝」与「确认丢失」（已提交但响应 500）
- **一键回放**：固定种子重放同一剧本 3 轮，最终状态哈希一致即结果稳定

## 启动

```bash
npm start          # 或 node server.js，默认 http://localhost:3000
PORT=8080 npm start
```

打开页面后：

1. 左侧「生成事件」→「立即上报」观察水位推进
2. 点「网络：在线」切换为离线，生成事件后再重连，观察补发与乱序
3. 开「服务端故障」，观察部分确认、重试与重复丢弃
4. 点「▶ 一键回放」验证 3 轮重放哈希一致

## 自测

```bash
npm test
```

覆盖：顺序入库、乱序待处理与晋升、重复丢弃、部分确认重试、确认丢失去重、3 轮回放哈希一致。

## API

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/events` | 批量上报，返回逐事件结果与 `acked` 序号列表 |
| GET | `/api/stats` | 看板快照（水位、待处理区、乱序直方图、日志） |
| GET | `/api/verify` | 一致性校验 + 确定性状态哈希 |
| POST | `/api/reset` | 重置状态，`{seed}` 可指定随机种子 |
| POST | `/api/config` | 故障模拟开关 `{flaky, rejectRate, ackDropRate}` |
